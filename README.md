# Personal academic website

A simple, free site for GitHub Pages. No build tools needed.

## Put it online
1. Create a GitHub account (if you don't have one).
2. Make a new **public** repository named exactly `yourusername.github.io`.
3. Upload everything in this folder (index.html, research.html, teaching.html, style.css, and the assets folder).
4. Go to **Settings → Pages**, set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
5. After a minute or two, your site is live at `https://yourusername.github.io`.

## Make it yours
- Replace "Your Name" and the bracketed text in all three .html files.
- Put your photo in `assets/images/` (e.g. `photo.jpg`) and update the `src` in index.html.
- Put your CV at `assets/files/CV.pdf`.
- Change colors at the top of style.css.
